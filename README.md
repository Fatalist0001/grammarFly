# grammarFly

**grammarFly** использует connectome MaleCNS как структурную основу спайковой
нейронной модели и исследует, может ли такая сеть приобрести простое временное
правило посредством синаптической пластичности.

Конкретная задача: может ли спайковая сеть, собранная по настоящей карте связей
мозга плодовой мухи, **сама обучиться грамматике** вида «сначала n букв A,
потом n букв B»:

```text
AB       → ACCEPT
AABB     → ACCEPT
AAABBB   → ACCEPT

A        → REJECT
AAB      → REJECT
ABB      → REJECT
ABAB     → REJECT
```

Правило грамматики в сеть заранее **не зашито** — она должна «вырастить» его в
процессе обучения. Это исследование способности структуры мозга к обучению,
а не подгонка модели под ответ.

---

## Простым языком: что тут происходит

### Ключевые понятия

- **MaleCNS** — карта связей мозга взрослого самца плодовой мухи (Drosophila):
  учёные перечислили нейроны и все их соединения.
- **Спайк** — короткий электрический импульс нейрона. Нейрон «разговаривает»
  спайками.
- **LIF-нейрон** — простая компьютерная модель нейрона: напряжение копится от
  тока; когда пробивает порог — нейрон выдаёт спайк и сбрасывается в исходное
  состояние.
- **Синапс** — контакт «от нейрона X к нейрону Y» с весом. Больше вес —
  сильнее влияние.
- **PoissonGroup** — источник случайных спайков (как «дождь из спайков»)
  с заданной частотой.
- **brian2** — симулятор спайковых сетей, на котором всё это считается.

### Схема эксперимента

```text
буква (A/B)
   ↓
искусственный орган (сыплет спайки 50 мс на свою букву)
   ↓
участок настоящего мозга мухи (LIF-нейроны + синапсы из карты MaleCNS)
   ↓
readout (фиксированное необучаемое правило): ACCEPT / REJECT
```

Вся «мозговая работа» должна происходить внутри сети. Органы и readout —
простые, **не обучаются и не знают грамматику**.

## Что уже сделано (шаг за шагом)

### 1. Подготовка окружения

- Python-окружение через `uv` (`.venv`), зависимости: `neuprint-python`
  (доступ к базе мозга мухи), `brian2`, `numpy`, `pandas`, `scipy`,
  `networkx`.
- Поставлен `numpy<2`: `brian2` несовместим с numpy 2.x.
- Проверена связь с MaleCNS через токен из `.env`. Токен нигде не
  захардкожен — читает функция `load_auth()`, а сам `.env` в git не
  коммитится.

### 2. Искусственные сенсорные органы

Два органа, которые преобразуют букву в нейронный сигнал:

- A-орган: на «покажи A» сыплет спайки 50 мс;
- B-орган: то же для «B».

Органы **не знают грамматику** — они лишь «моргают» на свою букву.
Интерфейс: `present("A")`, `present("B")`, `present_sequence("AABB")`.
Проверено на уровне спайков: A → спайки только в A-органе,
AABB → окна (A, A, B, B) по 50 мс каждое.

### 3. Искусственный readout

Фиксированное необучаемое правило: если спайков на ACCEPT-канале больше,
чем на REJECT-канале — ACCEPT, иначе REJECT. Без внешнего классификатора.

### 4. Генератор грамматики AⁿBⁿ

Класс `ABGrammar`:

- `positive(n)` — правильное слово «n букв A + n букв B»;
- `is_positive(word)` — проверка формы AⁿBⁿ;
- детерминированный перебор **всех** неправильных слов малых длин.

Разбиение на наборы (длины — количество букв):

| Набор       | Что входит                                                        |
|-------------|-------------------------------------------------------------------|
| train       | n=1..3 (AB, AABB, AAABBB) + неправильные слова длин 1–6 без BA    |
| validation  | неправильные слова длин 1–6 с перестановкой BA (B раньше A)       |
| test        | **новые длины n=4..6** + неправильные слова длин 7–13             |

Главный экзамен — test: если сеть распознает длины, которых не видела при
обучении, значит она выучила правило, а не вызубрила конкретные строки.
Размеры: train=27, validation=99, test=16256.

### 5. Маленький симулятор мозга (LIF)

Модуль `brain/lif.py`:

- `make_lif(n)` — группа LIF-нейронов: напряжение копится от тока,
  при достижении порога — спайк и сброс;
- `make_synapse(...)` — соединение с весом: при спайке в пост-нейрон
  вливается порция тока, пропорциональная весу.

Собрана маленькая тестовая сеть из 30 нейронов и проверена вся цепочка
«буква → орган → нейроны → readout».

> Найденный баг: в brian2 начальное напряжение по умолчанию 0, а порог −50 мВ,
> т.е. нейроны «палили» просто так. Начальное напряжение установлено на
> уровень покоя −70 мВ.

### 6. Какой участок мозга мухи выбран

Вместо всего MaleCNS взят удобный по размеру функциональный участок —
**правые доли грибовидного тела** (`aL(R)`, `a'L(R)`, `bL(R)`, `b'L(R)`):
классический центр памяти и обучения мухи, богатый рекуррентной динамикой.

- **3963 нейрона**, ~254 000 связей (295 884 ребра, 254 019 уникальных пар),
  средняя степень 73, гигантская компонента 3922 нейрона.

Участок сохранён локально в `data/malecns_mbRlobes/` (`nodes.csv`,
`edges.csv`) — симуляции больше не зависят от интернета и базы neuPrint.

### 7. Конвертер «настоящий мозг → симулятор»

Класс `MaleCNSGraph` (`brain/malecns.py`):

- читает `nodes.csv` / `edges.csv`;
- строит словарь «bodyId (идентификатор мушиного нейрона) → индекс в
  симуляторе»;
- хранит тип и instance каждого нейрона, его ROI;
- `build()` — создаёт LIF-группу на 3963 нейрона и синапсы с начальным весом:
  **число синапсов в connectome × константа шкалы весов** (по умолчанию
  калиброванные 0,001 нА).

Проверено без обучения: нет входного сигнала → тишина; есть стимул → спайки.

### 8. Проверка прохождения сигнала

Проба «живой» карты — поданы A, B, AB, AABB.

- **Вход** — KCs (входной каскад грибовидного тела): A-орган бьёт в одну
  группу KC, B-орган — в другую, непересекающуюся.
- **Выход** — MBONs (71 выходной нейрон доли): половина — канал ACCEPT,
  половина — REJECT.

Обнаружен и устранён «порог взрыва»: при константе ≥0,002 нА рекуррентная
сеть лавинно перевозбуждается (средняя частота с 7 Гц скачет до 136 Гц и
выше). Рабочая точка — **0,001 нА**: активность умеренная, не гаснет и не
насыщается.

Проверено:

- без входа — тишина (спонтанной активности нет);
- сигнал **не затухает и не насыщается**;
- A-буквы возбуждают KC группы A, B-буквы — KC группы B (в последовательности
  AABB окна сегрегированы);
- реакции на разные строки различимы → сеть хранит и передаёт информацию
  о временной последовательности;
- readout выдаёт ACCEPT/REJECT.

## Что дальше

По плану:

1. **Синаптическая пластичность** — обучение весов (первый кандидат — STDP,
   при необходимости reward-modulated STDP). Структура связей фиксирована,
   меняются только разрешённые веса.
2. **Обучающий цикл** — каждое упражнение подаётся через органы, результат
   сравнивается с правильным ответом, формируется награда/наказание.
3. **Главный экзамен** — после заморозки обученной сети проверяются **новые
   длины n=4..6**, которых не было в training set: выучила ли сеть правило,
   а не запомнила несколько строк.
4. **Контрольные эксперименты** — baseline без пластичности, случайный граф,
   реальная структура со случайными весами (отделить эффект именно структуры
   connectome).
5. **Анализ** — какие синапсы изменились, появилось ли внутреннее состояние
   «сколько A уже видели».

## Ограничения

- Это **не** полноценная модель мозга мухи. Connectome MaleCNS используется
  как структурная основа спайковой модели; упрощены динамика нейронов
  (LIF), нет химических различий синапсов (все трактуются возбуждающими),
  вход — искусственные органы.
- Первый эксперимент — сотни…несколько тысяч нейронов, а не весь MaleCNS.
