# Честное E/I разделение синапсов (data-driven) — полный протокол

Дата: 2026-09-22. Окружение: uv, Python 3.11, numpy 1.26.4, brian2 2.9.0.
Субстрат: правые доли грибовидного тела MaleCNS (3963 нейрона, 254 019 пар).

## Гипотеза эксперта

Текущая модель трактует все синапсы как возбуждающие — сеть не может
формировать избирательные (word-specific) устойчивые паттерны, только общий
подъём/спад. Настоящий MB использует структурное тормозное разделение
(APL/ГАМК). Гипотеза: честное E/I разделение — недостающий ингредиент для
персистентной памяти.

## Шаг 1 — Аудит данных

- Локальные `nodes.csv`/`edges.csv` не содержат информацию о типе синапса.
- Через neuprint API (`male-cns:v1.0`) получено поле `predictedNt` и
  консолидированное `consensusNt` для всех 3963 нейронов субграфа
  (покрытие 100%, средняя `predictedNtConfidence` = 0.797).
- `consensusNt` корректнее: **KC = acetylcholine** (в `predictedNt` KCs ошибочно
  помечены dopamine), APL = gaba, MBON01 = glutamate.
- Распределение `consensusNt`: acetylcholine 2667, glutamate 575,
  dopamine 302, **gaba 284**, unclear 106, octopamine 22, serotonin 7.
- Данные сохранены: `data/malecns_mbRlobes/nt.csv` (международный исходник
  в репозитории; скачивание — `data/fetch_nt.py`).

## Шаг 2 — E/I-типизация (реализация)

- `MaleCNSGraph.__init__` загружает `nt.csv` (consensusNt, fallback predictedNt).
- `inh_mask(inhibitory_nt=('gaba',))` — тормозные пары по NEUROТРАНСМИТЕРУ
  пре-нейрона; fallback: старый APL-only массив при отсутствии nt.csv.
- `make_synapse(inh=...)` — знак через переменную `sgn` (`I_post += w*sgn`),
  `sgn=-1` для тормозных (было из прошлого коммита для APL, обобщено).
- `build()` использует NT-маску вместо APL-only. Тормозных пар: **4895 из
  254 019 (1.9%)**, из них ~3747 от двух APL + ~1148 от остальных 282
  GABA-нейронов (ER2c/ER4d/ER5, MBON09/10/11/20/31/32, SMP/SIP/CRE и др.).
  KCs — возбуждающие (ни одна KC-пара не тормозная).
- `inh_scale` масштабирует силу торможения (единый коэффициент).

## Шаг 3 — Калибровка без обучения

- `test_propagation.py` (с E/I по умолчанию): сигнал A/B/AB/AABB проходит,
  не гаснет и не взрывается; mbon-частоты 77–300 Гц при шкале 0.001–0.016 нА.
- Все 8 тестов зелёные после типизации.

## Шаг 4 — Тест памяти после паузы с честным E/I

Протокол: `present_word(word, delay=150ms)`, отпечаток MBON за паузу,
K=5 реализаций Poisson. Метрики: `d_intra` (шум), `d_inter` (различие слов),
`ratio = d_intra/(d_intra+d_inter)` (~0.5 = сигнала нет), плюс решающая
метрика readout `pos%` = процент проб, где acc-канал > rej-канала в паузе.

Свипы (exp_memory_ei.py, exp_memory_ei2.py):

| w_scale | inh_scale | tau_m/tau_syn | итог |
|---|---|---|---|
| 0.001 нА | 0.5–2.0 | 10/2 | ratio 0.5–0.83, pos% ≈ 0 — нет |
| 0.002 нА | 1.0–3.0 | 10/2 | ratio 0.5–0.69 — нет |
| 0.003 нА | 1.0–4.0 | 10/2 | ratio 0.5–0.76 — нет |
| 0.001–0.004 нА | 2.0–8.0 | 20/5, 30/8 | ratio 0.43–0.83, pos% ≈ 0 — нет |
| 0.001 нА | 2.0 | 20/5 (лучший) | AB: ratio 0.43 (единственный выброс), BA: 0.50, pos% = 0 |

- **pos% = 0 во всех конфигурациях**: readout в паузе всегда REJECT,
  никакого слова в решении после 150 мс тишины нет.
- Единственный выброс (ratio 0.43 на AB) — нестабилен (для BA тот же выброс
  даёт 0.50) и не повторяется на соседних параметрах.

## Проверка действенности тормозных синапсов (exp_inh_effect.py)

Чтобы негативный вывод был содержательным, проверено, что ингибиция
действительно влияет:

| inh_scale | brain A | AABB | mbon(acc-rej) A / AABB |
|---|---|---|---|
| 0.0 | 881 | 5204 | −27 / −135 |
| 1.0 | 1519 | 4471 | −36 / −104 |
| 4.0 | 1217 | 4756 | −28 / −81 |
| 16.0 | 722 | 3715 | −1 / −1 |

Торможение эффективно (суммы спайков и acc-rej-дисбаланс меняются, при
inh=16 сеть почти замолкает), но селективного удержания не создаёт.

## Шаг 6 — Итоговый вывод (сильнее предыдущего)

> Даже с честным E/I разделением синапсов по данным коннектома
> (neurotransmitter-derived sign, 4895 тормозных пар включая полный APL-контур
> и 282 дополнительных GABA-нейрона) локальный подграф правых MB-долей не
> формирует word-специфичных персистентных состояний после паузы
> (100–200 мс). Тормозных пар всего 1.9% от всех связей; ингибиция
> эффективна, но изотропна и не структурирует привлекатели по словам.

**Следующий кандидат по плану эксперта:** рекуррентные связи через
**ellipsoid body** или расширение на смежные структуры коннектома, а не
типизация синапсов внутри уже выбранного подграфа.
