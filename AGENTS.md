# AGENTS.md — grammarFly

## Проект

`grammarFly` исследует, может ли спайковая сеть, построенная на connectome
взрослого самца Drosophila (MaleCNS, janelia neuPrint), сама обучиться простой
грамматике `AⁿBⁿ` за счёт синаптической пластичности.

**Единственный источник истины по целям и порядку работы — `PLAN.md`.**
Перед началом любой реализации прочитать `PLAN.md` целиком.

План реализуется строго последовательно (разделы 1–15/16). На каждом этапе
сначала минимальная рабочая реализация + проверка, только потом переход дальше.

## Отметки прогресса в PLAN.md

- По ходу реализации **отмечать выполненные пункты** прямо в `PLAN.md`.
- Заголовок выполненного раздела помечать `[x]`, например:
  `# 1. Изучить существующий проект [x]`.
- В конце завершённого этапа — краткая заметка в PLAN.md, что сделано и чем проверено.
- Не удалять пункты и не менять их смысл; только добавлять `[x]` и заметки.

## Окружение и команды

- Управление через `uv`, окружение — `.venv` (создано, Python 3.11).
- Запуск скрипта: `uv run <script>.py` (например `uv run test.py`).
- Добавить зависимость: `uv add <pkg>` или `uv pip install <pkg>`.
- Известные установленные пакеты: `neuprint-python`, `numpy`, `networkx`, `pandas`, `scipy`.
- На этапах 5+ потребуется установить `brian2`.

## Секреты и .env

- `.env` содержит токен: строка вида `AUTH=<token>`.
- `.env`, `.venv/`, `__pycache__/` исключены через `.gitignore`, в git не коммитить.
- Токен из `.env` читается без сторонних библиотек — см. `load_auth()` в `test.py`.
- Никогда не захардкоживать и не логировать токен.

## Конвенции и ограничения

- Не удалять существующий код без необходимости; новый эксперимент — в отдельной структуре/папках.
- Искусственные органы и readout **не должны знать грамматику** и не обучаться.
- Правильный ответ используется только как внешний обучающий сигнал (reward/punishment) на этапе обучения.
- Не пытаться симулировать весь MaleCNS; первый эксперимент — сотни…несколько тысяч нейронов.
- Структура connectome фиксирована; обучаются только разрешённые синаптические веса.
- Baseline (без пластичности) обязателен.
- Не называть систему «полноценной моделью мозга мухи»; формулировка — из раздела 16 PLAN.md.
- Комментарии в коде не добавлять без необходимости (следовать стилю существующего кода).

## Критерий успеха

Заметное улучшение относительно необученной сети и, главное, распознавание новых `n`,
отсутствовавших в training set (генерализация).
